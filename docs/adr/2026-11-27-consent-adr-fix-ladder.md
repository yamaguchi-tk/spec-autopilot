# ADR: 合意の ADR が満たす約束に直し方の段の行を足し、形は lint、意味は照合役で見る

- 日付: 2026-11-27
- 状態: Accepted
- spec: docs/specs/2026-11-27-consent-adr-fix-ladder

## Context
人が「目的に対して手段が最善か？ 枠組み変えたらもっと良い方法がある　みたいな視点がない」と指摘した。

枠組みを変える問い（直し方の 4 段）は、同じ要件で 3 巡失敗した後の作り直し（references/dead-end.md の 2）にしか無い。合意の段では、commands/autopilot.md の A の 4 が「作り方の案を 2〜3 個」とだけ求め、雛形（references/adr-template.md:27）は段の行を作り直しの ADR だけに限っている。実物の合意の ADR（docs/adr/2026-11-26-input-table-test-cell.md、docs/adr/2026-11-26-night-notes-short-run.md）は、どこで分岐するかの局所の案だけを並べている。docs/adr の 26 本のうち、行頭の段の行を持つのは作り直しの 1 本だけである。

「選択肢が同じ枠に収まったせいで起きた実害」の記録はまだ無い。人が名指しで頼んだ視点なので入れ、効果は導入の前後の件数で見る。

## 選択肢
1. 要らなくする: 既にある相談役（fable-advisor の「そもそもどうあるべきか」）と、承認のときの人の目に任せ、何も足さない
   - 得るもの: 変更が無い
   - 失うもの: 合意の段では相談役は既定で回らない（autopilot.md の B の 3）。人の目は、ADR に枠の違う案が無いことに気づけない（今がその状態で、人が指摘した）
2. 入力の約束を変える: 合意の ADR が満たす約束に段の行を足す。形は lint が rootcause.check で見て、意味は照合役の新しい項目で目的に当てる。雛形と autopilot.md の文言も同じ変更で直す
   - 得るもの: 案を出す側（雛形・手順）と確かめる側（lint・照合役）の両方に問いが入る。段の正本は FIX_ORDER の 1 つのまま。lint を通る 3 つの承認すべてに効く
   - 失うもの: 合意の ADR が 1〜4 行増える。形だけ埋めた理由は CLI を通る。軽量フローには照合役が無い
3. 設計を変える: 合意の段に、枠組みを変える案だけを出す専用の agent を足し、毎回回す
   - 得るもの: 書く本人と別の役が案を出す
   - 失うもの: spec ごとに agent が 1 本増え、費用と待ちが増える（相談の決着に 38 分かかった事例がある）。案を出す役と照合役の役割が重なる
4. 局所の継ぎ足し: 照合役の表に 1 項目足すだけ、または autopilot.md の文言を能動的にするだけ
   - 得るもの: 変更が最小
   - 失うもの: 照合役だけでは書く側が変わらず、毎回 ng の往復が出て、軽量フローに効かない。文言だけでは確かめる役が無く、文の継ぎ足しで再発しやすい（docs/adr/2026-11-25-fix-order-park.md が、同じ理由で文だけの案を退けた前例）

## Decision
2 を選ぶ。spec の目的（合意の ADR が上の段を退けた理由を必ず持ち、書いた本人でない役が読む）に届くのは 2 だけである。3 は 2 の確かめる役を agent 1 本で重ねるもので、費用に見合う観測が無い。検査は、自走中の spec を止めないよう、初回の合意（phase が discovery・queued で、目的の spec の承認〔--goal〕でないとき。lint の first_agreement と同じ条件）のときの lint にだけ置く。

- 直し方: 入力の約束を変える
- 退けた: 要らなくする（相談役は合意の段で既定では回らず、人は ADR に枠の違う案が無いことに気づけないので、今の仕組みのままでは目的に届かない）

## Consequences
- 新しく合意する spec の ADR は、段の行が無いと lint と承認で止まる。既にある ADR は直さない
- 夜の行列に、この版より前に承認した queued の spec があると、着手の lint で止まりうる（行列は夜の間に消化されるので、件数は少ない）
- 退けた理由の中身は CLI で見ないので、形だけ埋めた理由は照合役と人の目で拾う。軽量フローでは形だけになる
- 効果は、導入後の合意の ADR で、選んだ段が「局所の継ぎ足し」より上だった本数と、照合役の新しい項目の ng の数で見る
