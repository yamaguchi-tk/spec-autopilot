# 相談役は承認の門と名指し・IaC の初回だけに回し、ほかは main の案を検証役に直接当てる

- 状態: 採用
- spec: docs/specs/2026-11-28-fewer-advisor-calls/spec.md
- 直し方: 要らなくする
- 退けた: 入力の約束を変える（相談役に渡す材料を減らしても起動の本数と待ちは減らない）
- 退けた: 設計を変える（承認の門の判定を変えて子の承認から相談を外すと、記録で 47 件中 26 件効いていた `承認: 否` と反証ありを失う）
- 退けた: 局所の継ぎ足し（相談役を回す条件を今の 2 段に足しても、効いた証拠の無い 1 段目が残る）
- 価値観で退けた: 子の承認の門から相談役を外す（効いている止め役を外すのは、依頼の「不要なら外す」に当たらない）

## 背景
2026-11-14〜11-28 の transcript で相談役・検証役の起動を数えた（相談 569 件、約 3,162 分。resume の重複を tool_use の id で除いた）。1 段目の推奨が main の案を変えた証拠は 0 件（main の案と推奨を並べて比べられたのは 3 件で、3 件とも同じ案）。判定できた 192 件のうち効いたのは 101 件で、ほぼすべてが検証役が repo の事実（path:行）との食い違いを見つけた件か、子の承認の `承認: 否` だった。検証役が path:行 を引かなかった 3 件は全部反証なし。レビュー指摘の直し方は 238 件・約 32 時間で、8 割は検証役の無い相談役だけの起動で効き目を判定できない。

## 決定
1. 1 段目の相談役（fable-advisor）を回すのは、目的の spec の子の承認（`--queue --by-advisor`）、block の後の承認し直し（`--by-advisor`）、人が名指ししたとき、IaC の初回の apply を含む spec の 4 つだけにする。承認の門の判定（2 本の記録を求める）は変えない
2. それ以外の迷い（価値観で残る案が 2 つ以上・人に戻るときの選択肢・レビュー指摘の直し方）は、main が価値観で選んだ案の `推奨:`・`理由:`・`引いた決定:` を、根拠に repo の事実（path:行・コード・引いた決定）があるときだけ advice-checker に直接渡して反証を探させる。根拠に repo の事実が無ければ回さない
3. 価値観で案が 1 つに絞れたときは、相談役も検証役も回さない

## 結果
- 起動の本数が、承認の門と名指し・IaC の初回を除いて 1 本以下になる
- 検証役が main の案を受け取るので、main の案に寄った材料で反証を探す。検証役は反証を探す役なので影響は小さいと見るが、測っていない
