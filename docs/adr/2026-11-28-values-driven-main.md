# main が価値観で案を選び、人に問う範囲を 3 つに絞る

- 状態: 採用
- spec: docs/specs/2026-11-28-values-driven-main/spec.md
- 直し方: 入力の約束を変える
- 退けた: 要らなくする（今の相談役の規則と相談役の価値観の節のままでは、main が価値観を読まずに反する案を並べ、問う範囲も絞られないので、夜の停止が残る）
- 退けた: 設計を変える（turn の終わりの文が問いかを hook が見分ける手がかりが無く、測る手順も無い）
- 退けた: 局所の継ぎ足し（案を 2〜3 個並べる今の形のまま相談役の推奨で進むと、価値観に合わない案が並ぶこと自体が残る）

## 背景
2026-11-28 の夜、目的の spec の子を 3 本マージした後、03:19 に R3 の子（親の要件を狭める点）を人に問うて turn を終え、08:14 に人が返すまで約 5 時間止まった。並べた選択肢のうち「狭めて承認する」は価値観（依頼を縮めない）に合わず、人の答えは「直して出し直す」だった。

## 決定
1. main は案を作る前に価値観を読む（repo と利用者の CLAUDE.md の設計原則、spec・ADR の人の決定、目的・非目標）。反する案は選択肢に並べず、ADR の `- 価値観で退けた:` の行かタスクのメモに 1 行で残す（直し方の段の `- 退けた:` と分ける）。数をそろえるために案を作らない
2. 残った案が 1 つなら問わずに進み、理由を ADR かタスクのメモに残す
3. 人に問うのは (a) 人しか持たない事実、(b) 利用者の規則が 1 操作ごとに求める許可、(c) 目的を変える決定（要件を落とす・非目標を広げる）だけ。ほかは、main が価値観で選んだ案を相談役（fable-advisor）と検証役（advice-checker）に確かめさせ、相談役の推奨が main の案と同じで反証なしなら問わずに進む。違うか反証ありなら、自走中は当たる要件だけ park に積んで他を続け、人がいる場で自走していないときは食い違いを添えて問う
4. 相談役の役は、main が価値観で選んだ案が人の選びと同じかを確かめることにする

## 結果
- 夜の間の問いが、事実・許可・目的の変更だけに減る
- main と相談役が食い違ったときだけ人に届くので、人が見る選択肢は価値観に合うものだけになる
