# ADR: セッション単位の上書きを、セッション id ごとのファイルで既定の上に重ねる

- 日付: 2026-11-28
- 状態: Accepted
- spec: docs/specs/2026-11-28-role-model-setup-session

## Context
人は「セッション単位で変えられるのと　デフォルト値と両方あるのが理想」と言った。1 本目・2 本目で既定（models.md）の層ができる。相談役の推奨（fable-advisor、advice-checker は反証なし）は、3 本目として既定の上にセッションの層を足す形だった。

## 選択肢
1. セッション id ごとのファイルに同じ行の形で書き、読み方を 1 つの関数にしてセッション → 既定 → 同梱の順で引く: 層を 1 つ足すだけで、検査を使い回せる
2. 環境変数で上書きする: セッションの外から渡す必要があり、setup の対話から書けない
3. セッションの上書きを相談・検証・照合だけにする: 人の発言より狭く、受けない役の分岐が増える

## Decision
1 を選ぶ。5 つの役すべてを受ける。

- 直し方: 設計を変える
- 退けた: 要らなくする（既定の層だけでは、既定を変えずに今のセッションだけ段を変える道が無い）
- 退けた: 入力の約束を変える（起動に model を渡す約束にすると、別名の解決と effort の固定ができない）

## Consequences
- 終わったセッションのファイルが置き場に残る
- fork・/clear で id が変わると上書きが切れる（compaction・resume では同じ id のまま効く）
