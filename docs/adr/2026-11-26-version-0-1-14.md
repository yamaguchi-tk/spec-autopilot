# ADR: 5 本の PR の直しを届けるため、版数を 0.1.14 に上げる

## 状況
版数は PR 64（commit 8a038fa）で 0.1.13 になった。その後に PR 51・63・57・58・66 が main に入り、plugin の中身（テストを除く）が 10 ファイル変わったが、marketplace から入れた人にはまだ届いていない。

## 決定
plugin.json の version を 0.1.13 から 0.1.14 に上げる（パッチの版を 1 つ）。版数のテストは、0.1.12 を超えたことを見るものを、0.1.13 を超えたことを見るものに置き換える。

## 退けた案
- 0.1.11 にする: 人は最初 0.1.11 と言ったが、main はすでに 0.1.13 で、版数が下がると入れた人の更新に届かない
- 0.2.0 に上げる: 直しは承認の判定・NOTE の条件・文書の文言で、使い方を変える機能を足していない
- 版数のテストを足して 2 本並べる: 0.1.13 を超えたことは 0.1.12 を超えたことを含み、同じことを見るテストが重なる
