# ADR: PR 59 の直しを届けるため、版数を 0.1.13 に上げる

## 状況
PR 59 で advice-checker の定義を直したが、変えるファイルを 1 つに保って軽量フローの大きさ S に入れるため、版数は上げなかった。0.1.12 の後に plugin の中身（テストを除く）で変わったのはその 1 行だけで、marketplace から入れた人にはまだ届いていない。

## 決定
plugin.json の version を 0.1.12 から 0.1.13 に上げる（パッチの版を 1 つ）。版数が 0.1.12 を超えたことをテストで確かめる。

## 退けた案
- 次に plugin の中身を変える PR で一緒に上げる: その PR がいつ出るか決まっておらず、それまで直しが届かない。人は今上げるよう頼んだ
- 0.2.0 に上げる: 変わったのは agent の定義の 1 行の文言で、挙動を足していない
