# ブラウザの数当てゲーム

- ADR: docs/adr/2026-11-27-number-guess.md

## 目的
人の依頼:「ブラウザで遊べる数当てゲームを作りたい」。開いてすぐ遊べるようにする。

## 要件
- R1: `index.html` を開いたとき、ゲームは 1〜100 の数を 1 つ決め、入力欄と「当てる」ボタンと「1〜100 の数を当ててください」を表示する。
- R2: 数を入れて「当てる」を押したとき、ゲームは答えより小さければ「もっと大きい」、大きければ「もっと小さい」、同じなら「正解（<回数> 回）」を表示する。
- R3: 1〜100 の整数でない値を入れて「当てる」を押したとき、ゲームは「1〜100 の整数を入れてください」を表示し、回数を数えない。
- R4: 正解の後に「もう一度」を押したとき、ゲームは新しい数を決め、回数を 0 に戻す。

## 非目標
- 最高記録の保存（足すなら localStorage に最少回数を残す）
- 難しさの選択（足すなら範囲を 1〜1000 にする）

## 前提
- 目的に届く: 手元のブラウザで遊べるところまで
- 運用: 依頼者が `index.html` をブラウザで開く
- 普通のやり方: なし（数当ては決まったルールの無い遊び）
- 過去: なし（新しく作る repo）
- 前提: なし（新しく作る repo）

## 作り方
素の HTML と JavaScript で、判定の関数を DOM から分ける。
