# ブラウザで遊べるシンプルな落ち物パズル（テトリス風）

- ADR: docs/adr/2026-11-27-plain-html-canvas.md

## 目的
「ブラウザで遊べるシンプルなテトリスのようなゲームを作りたい」。ファイルをブラウザで開くだけで、移動・回転・落下・行の消去・スコアの基本操作で遊べる状態にする。「基本の操作だけでよい」ので、それ以外の機能は足さない。

## 要件
- R1: `index.html` をブラウザで直接開いた（file://）とき、ゲームは 10 列×20 行の盤面、「スコア: 0」、操作説明（日本語）を表示し、ミノを 1 つ盤面の上端中央に出して落下を始める。
- R2: プレイ中に ← か → を押したとき、ミノは 1 マス左右に動く。動いた先が盤面の外か固定ブロックに重なるなら動かない。押し続けている間は繰り返し動く。
- R3: プレイ中に ↑ を押したとき、ミノは時計回りに 90 度回転する。回転後の形が盤面の外（左右・上下）か固定ブロックに重なる場合は、横に 2 マス以内でずらして重ならない位置があればそこで回転し、無ければ回転も移動もしない。↑ は押し続けても 1 回と数える。
- R4: 800 ミリ秒の tick ごとに、現在の位置からミノが 1 マス下に動けるなら下がり、動けないならその位置で固定して次のミノを出す。
- R5: プレイ中に ↓ を押したとき、ミノは 1 マス下に動く。下に動けないなら何もしない（固定は R4 の tick が行う）。押し続けている間は繰り返し下がる。
- R6: プレイ中に スペース を押したとき、ミノは真下の落ちられる一番下まで移動し、その場で固定して次のミノを出す。次の tick はその操作の 800 ミリ秒後にする。スペースは押し続けても 1 回と数える。
- R7: ミノを固定して横一列がすべて埋まった行ができたとき、ゲームはその行をすべて消し、上の行を消した行数だけ下に詰める。
- R8: 行を消したとき、ゲームは同時に消した行数に応じて 1 行=100、2 行=300、3 行=500、4 行=800 点を加算して表示を更新する。落下の操作には点を付けない。
- R9: 次のミノが出現位置で固定ブロックに重なるとき、ゲームは「ゲームオーバー」と最終スコアを表示し、落下とミノの操作を止める。
- R10: ゲームオーバー中に Enter を押すか「もう一度」ボタンを押したとき、ゲームは空の盤面とスコア 0 で最初から始める。Enter は押し続けても 1 回と数える。
- R11: プレイ画面を表示している間、盤面は縦横比 1:2 で高さがウィンドウの高さの 80% になり、矢印キーとスペースを押してもページはスクロールしない。
- R12: ミノを出すとき、ゲームは 7 種類（I・O・T・S・Z・J・L）からランダムな順で出し、種類ごとに違う色で描く。

## 非目標
- 足すなら: 次のミノの予告表示
- 足すなら: 消した行数に応じた速度上昇（レベル）。今回の落下の速さは一定
- 足すなら: 一時停止
- 足すなら: 最高点の保存
- 足すなら: ホールド・落下位置の影（ゴースト）
- 足すなら: スマホのタッチ操作
- 効果音・BGM・オンライン対戦・テーマ切り替え
- GitHub の repo の作成・公開（依頼の指定）

## 前提
- 目的に届く: キーボードのある PC のブラウザで遊べるところまで届く。スマホ（タッチ操作）では遊べない
- 運用: 利用者が `index.html` をブラウザで開いて遊ぶ。保守は `node --test` でロジックのテストを回す。サーバーもビルドも要らない
- 普通のやり方: 盤面 10×20 と 7 種を 1 巡ずつ出す方式（7-bag）が広く使われる。点数の 100/300/500/800 は一部の作品の値で、公式の標準とは確認できていない。出典は https://tetris.fandom.com/wiki/Guideline（検索結果の要約で見ただけで、本文は読んでいない）
- 過去: なし（新しく作る repo）
- 前提: キーを押し続けると、ブラウザは keydown を繰り返し送り、繰り返し分は `event.repeat` が true になる
  - URL: https://developer.mozilla.org/en-US/docs/Web/API/KeyboardEvent/repeat
- 前提: file:// で開いたページは ES modules を読み込めないので、classic script を使う
  - URL: https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS/Errors/CORSRequestNotHttp
  - 未確認: classic script が file:// で読めることは、自走の QA（R1）で実物で確かめる
- 前提: 手元の Node は組み込みのテストランナー（node:test）を使える版である
  - コマンド: `node -v` → v22.17.0

## 作り方
素の HTML + Canvas + classic script（ES modules を使わない）。依存もビルドも無し。
- `index.html`: 画面と見た目
- `game.js`: DOM に触らないゲームのロジック（盤面・移動・回転・tick・消去・スコア・7-bag）。ブラウザではグローバル、Node では `module.exports` で読む
- `main.js`: 描画・キー入力・tick のタイマー
- `test/game.test.js`: `node --test` の単体テスト

- 回転のずらしは、横に -1、+1、-2、+2 マスの順に試し、最初に重ならない位置を使う
- ミノの選び方は 7-bag（7 種を 1 巡で 1 回ずつ、並びはランダム）

普通のテトリスの項目のうち、扱うのは盤面 10×20（R1）・7-bag・同時消しで増える点数（R8）。範囲外は、予告・ホールド・ゴースト・速度上昇（非目標）、公式の回転規則（SRS。上の簡単なずらしで代える）、T-spin などの追加得点、接地後の固定の猶予。

退けた案と理由は ADR に書く。

## QA の方向性
| 要件 | 段 | 確かめ方 | 合格基準 |
|---|---|---|---|
| R1 | 手元で実物 | ヘッドレスのブラウザで file:// の index.html を開く | コンソールのエラーが無く、盤面・「スコア: 0」・操作説明が見え、ミノが時間とともに下がる |
| R2 | 手元で実物 | 単体テスト（壁・固定ブロックの境界）とブラウザの ← →（長押しを含む） | 1 マス動き、壁と固定ブロックでは位置が変わらず、長押しで繰り返し動く |
| R3 | 手元で実物 | 単体テスト（通常・壁際のずらし・全部重なる場合）とブラウザの ↑ | 時計回りに回り、壁際はずらして回り、全部重なれば形と位置が変わらない |
| R4 | 手元で実物 | tick を明示的に呼ぶ単体テスト（下がる・固定する・接地後に横へ動いて再び下がる）とブラウザで放置 | tick ごとに現在の位置で判定され、固定は下に動けない tick でだけ起きる |
| R5 | 手元で実物 | 単体テストとブラウザの ↓ | 1 マス下がり、接地中は固定も移動もしない |
| R6 | 手元で実物 | 単体テストとブラウザのスペース（長押しを含む。タイマーは時刻を進めて確かめる） | 一番下で即固定して次が出て、次の落下は 800 ミリ秒後。長押しで落ちるのは 1 個 |
| R7 | 手元で実物 | 単体テスト（1〜4 行、離れた 2 行）とブラウザで 1 行消す | 埋まった行だけが消え、上の行が消した数だけ下がる |
| R8 | 手元で実物 | 単体テストとブラウザの表示 | 100/300/500/800 が加算され、↓ とスペースでは増えない |
| R9 | 手元で実物 | 単体テストとブラウザで積み上げる | 「ゲームオーバー」と最終スコアが出て、tick とキーで盤面が変わらない |
| R10 | 手元で実物 | ブラウザで Enter とボタンの両方 | 空の盤面・スコア 0 で落下が再開し、タイマーが二重にならない |
| R11 | 手元で実物 | ブラウザで大きさを 2 通りにして測り、矢印とスペースを押す | 盤面の高さがウィンドウの高さの 80%（±2%）、幅がその半分で、scrollY が 0 のまま |
| R12 | 手元で実物 | 単体テスト（乱数を差し替えて 14 個）とブラウザの目視 | 7 個ずつに全種が 1 回ずつ現れ、乱数を変えると順が変わり、7 色が違う |
