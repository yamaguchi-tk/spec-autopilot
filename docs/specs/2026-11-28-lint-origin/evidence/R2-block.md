# R2 を今の作り方で満たせない理由

- 再現: `python3 .autopilot-qa/check.py` の「R2 人の発言の後に要件の文を lint した中身へ戻し連番も変えても断る: fail」
- 手順: lint(A) → lint せずに要件の文を B に直す → 人の発言 → 要件の文を A に戻し、同時に `- ADR:` の連番を変える（A'）→ approve。approve が exit 0 で通る
- 原因: 承認の門の起点を決める材料は、lint の時点の記録（連番を外したハッシュ・本文全体のハッシュ・時刻・mtime）と、今の spec.md だけ。B は lint を通っていないので記録に残らない。A' は「lint の時点から連番の桁だけ違う」に当たり、A→A'（意図どおりの改番）と A→B→A' を見分ける材料が無い
- 直せたもの: A→B→A（完全に戻す）と、mtime だけ変わった場合は T4 で止まる
- 直す道（どれも spec の合意のし直しが要る）:
  1. 人の発言のとき（UserPromptSubmit の hook）に、記録している spec の中身のハッシュを残し、approve は「今の中身と同じハッシュを見た人の発言」があるかで判定する（hooks を変える。影響範囲が増える）
  2. 「lint を通さずに直して人に示し、返事の後に連番ごと戻す」場合を R2 の外とし、非目標と ADR の限界に書く（今の実装のままマージできる）
