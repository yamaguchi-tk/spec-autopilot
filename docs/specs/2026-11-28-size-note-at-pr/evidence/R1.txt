一時の git repo（.autopilot-qa/size-note-runs/ の下）で、tip の CLI と base（cbbdac4）の CLI を同じ作り方の repo に回して比べた。
grownL = 申告 M で承認し、差分が L に育った spec。stayM = 申告 M で M のまま。declL = 合意し直しで申告を L にした spec。
unfinished_grownL = grownL でタスクが残る（ERROR あり）。unreadable = 承認後に大きさの行を読めない値にした。unapproved = 承認前。

ほかに同じスクリプトで確かめたこと（どれも一致）:
- 終了コード: 6 通りすべてで check --stage pr の終了コードが tip と base で同じ（NOTE の有無で変わらない）
- --stage なしの check: 6 通りすべてで tip と base の stdout・終了コードが同じで、L の NOTE を出さない
- done: grownL・stayM・declL で、tip と base の done の NOTE の行と終了コードが同じ（grownL・declL は L の NOTE あり、stayM は無し）
- check --stage pr の L の NOTE の行は、同じ repo の done の L の NOTE の行と同じ本文
- どの出力にも `NOTE: NOTE` の二重の接頭辞と Traceback が無い
