一時の git repo（.autopilot-qa/size-note-runs/ の下）で、tip の CLI と base（cbbdac4）の CLI を同じ作り方の repo に回して比べた。手元のパスは <repo>・<worktree> に伏せた。
grownL = 申告 M で承認し、差分が L に育った spec。stayM = 申告 M で M のまま。declL = 合意し直しで申告を L にした spec。
unreadable = 大きさの行を読めない値にし、承認の hash をそれに合わせた spec（この版より前に形を検査せずに承認した spec）。
unfinished_grownL = grownL でタスクが残る（check が ERROR を返す）。unapproved = 承認前。
nospec_unapproved = 承認前の spec から spec.md を消した。nospec_done・nospec_grownL = 承認した spec から spec.md を消した（T3 の対象）。
期待: check が通る spec では、L（grownL・declL・unreadable）だけ --stage pr で NOTE が出て、終了コードは base と同じ（0）。M（stayM）では出ない。
check が ERROR を返す spec では NOTE を出さず、終了コードは base と同じ（1）。--stage なしの check と done の NOTE は base と同じ。
T3: 承認した spec の spec.md が無いとき、tip の check（既定・--stage pr）と done は Traceback でなく `ERROR: spec.md が無い` の 1 行・終了コード 1 で終わり（base は FileNotFoundError の Traceback）、status は残りにその行を出す。
