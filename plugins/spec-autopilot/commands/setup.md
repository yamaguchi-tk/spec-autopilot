# /spec-autopilot:setup

役ごとの既定の段を、手元の設定 `models.md`（`SPEC_AUTOPILOT_HOME`、無ければ `~/.claude/spec-autopilot` の下）に書く。役は実装・評価・相談・検証・照合の 5 つ。実装・評価の段は、以後に `autopilot.py init` が作る spec.md の `## モデル` に写る（作った後の spec は変わらない。直すなら spec の `## モデル` を直す）。相談・検証・照合の段は spec には写らず、次に始めたセッションの SessionStart が、main に既定の agent の代わりに選んだ段の agent を使わせる（走っているセッションには効かない）。選べるのは段の表の段だけ。

書き先は 2 つある。**既定**（上の `models.md`）は、以後のセッションの全部に効く。**このセッションだけ**は、手元の置き場の `sessions/<セッション id>.models.md` に書き、今のセッションにだけ効く（既定は変えない）。役ごとの段は、セッションの上書き → 手元の既定 → 同梱の既定の順で決まる。セッションの上書きのうち、相談・検証・照合は、読み替えの行がそのコマンドの出力に出て、compaction や resume で始まり直した後の SessionStart の指示にも同じ段で入る。実装・評価は、このセッションで後から `autopilot.py init` が作る spec の `## モデル` にだけ写る（作った後の spec は変わらない）。/clear と fork は新しいセッション id になり、上書きは切れて既定に戻る。

この本文のコマンドは、`${CLAUDE_PLUGIN_ROOT}/scripts/ladder.py` をそのまま実行することを指す（シェル変数に入れない）。

## 手順

1. 今の設定と、役ごとの受ける段を読む。

```
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/ladder.py" show
```

出力は役（実装・評価・相談・検証・照合）ごとに「受ける段（安い順）・既定の段・手元の設定の段（無ければ なし）・このセッションの段（無ければ なし）」と、設定のファイルのパス（今のセッションが分かれば、セッションのファイルのパスも）を示す。

2. AskUserQuestion で、先に書き先を 1 問だけ聞く。選択肢は「既定に書く」と「このセッションだけ」の 2 つ。以降の手順は、選んだ書き先で変わる所を `既定:`・`セッション:` で分ける。

3. AskUserQuestion で、役ごとに 1 問ずつ人に 1 つ選ばせる。AskUserQuestion は 1 回に 4 問までなので、1 回目に実装・評価・相談・検証の 4 問、2 回目に照合の 1 問を聞く（1 回に 5 問受ける環境なら 1 回にまとめてよい）。選択肢は `show` の出力から作る。
   - 選択肢は 4 個以内にする（AskUserQuestion は 2〜4 個しか受けない）
   - 先頭に、今の段を「今のまま」として置く。今の段は、セッションの上書きがあればその段、無ければ手元の設定の段、それも無ければ既定の段（`show` の「このセッション」・「手元の設定」・「既定」の順）
   - 戻り先の段を決める。`既定:` は既定の段。`セッション:` は手元の設定の段（無ければ既定の段）
   - 今の段が戻り先と同じなら、続けて、その役の受ける段のうち今の段以外を安い順に置く（「既定に戻す」は置かない。「今のまま」と同じ中身になる）
   - 相談と検証を同じ model にすると、別の目で見る効きが減る。選ぶ前に 1 行そう添える
   - 今の段が戻り先と違うなら、続けて「既定に戻す」（`既定:` は既定の段を書く。`セッション:` はセッションの上書きの行を消して、手元の設定か既定の段に戻す）を置き、そのあとに、受ける段のうち今の段と戻り先の段以外を安い順に置く（戻り先の段は「既定に戻す」で選べるので、段としては重ねない）
4. 選んだ結果を書く。今のままを選んだ役は何も打たない。`既定:` で段を選んだ役は、次のコマンドを打つ（複数の役が段なら 1 回にまとめてよい）。

```
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/ladder.py" setup --impl <段> --review <段> --advisor <段> --checker <段> --spec-checker <段>
```

   - 段を選んだ役の旗だけを付ける。実装 `--impl`・評価 `--review`・相談 `--advisor`・検証 `--checker`・照合 `--spec-checker`
   - 「既定に戻す」を選んだ役は、役ごとに `setup --reset 実装`・`setup --reset 評価`・`setup --reset 相談`・`setup --reset 検証`・`setup --reset 照合` のどれかを打つ（その役の行だけを消す）。全部の役を戻すなら `setup --reset` を打つ（models.md を消す）
   - 受けない段を渡すと 0 以外で終わり、受ける段を出して models.md を変えない。そのときは出力のとおりに選び直させる

   `セッション:` で段を選んだ役は、同じ旗に `--session` を付けて打つ（`models.md` は変えない。渡していない役のセッションの行は残る）。

```
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/ladder.py" setup --session --impl <段> --review <段> --advisor <段> --checker <段> --spec-checker <段>
```

   - 「既定に戻す」を選んだ役は、役ごとに `setup --session --reset 実装`・`setup --session --reset 評価`・`setup --session --reset 相談`・`setup --session --reset 検証`・`setup --session --reset 照合` のどれかを打つ（その役のセッションの行だけを消す）。全部の役を戻すなら `setup --session --reset` を打つ（このセッションのファイルを消す。`models.md` は消さない）
   - 今のセッションが分からない（`CLAUDE_CODE_SESSION_ID` が無い、または形に合わない）と、`--session` は 0 以外で終わり、どのファイルも変えない。そのときは、既定に書くか、セッションを始め直してから打つよう人に伝える
   - 相談・検証・照合の出力には「読み替え（相談）: fable-advisor → …」の行が出る。実装・評価は、このセッションで後から init する spec にだけ効く
5. 打ったコマンドの出力（書いたファイルのパスと中身、または既定に戻ったこと）を、そのまま人に示す。最後に `show` を打ち直して結果を確かめてもよい。
