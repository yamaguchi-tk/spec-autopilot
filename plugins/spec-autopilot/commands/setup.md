# /spec-autopilot:setup

役ごとの既定の段を、手元の設定 `models.md`（`SPEC_AUTOPILOT_HOME`、無ければ `~/.claude/spec-autopilot` の下）に書く。書いた段は、以後に `autopilot.py init` が作る spec.md の `## モデル` に写る。作った後の spec は変わらない（直すなら spec の `## モデル` を直す）。選べるのは梯子の段だけで、照合役・相談役のモデルは変えない。

この本文のコマンドは、`${CLAUDE_PLUGIN_ROOT}/scripts/ladder.py` をそのまま実行することを指す（シェル変数に入れない）。

## 手順

1. 今の設定と、役ごとの受ける段を読む。

```
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/ladder.py" show
```

出力は役（実装・評価）ごとに「受ける段（安い順）・既定の段・手元の設定の段（無ければ なし）」と、設定のファイルのパスを示す。

2. AskUserQuestion で、役ごとに 1 問ずつ（実装役・評価役の 2 問）人に 1 つ選ばせる。選択肢は `show` の出力から作る。
   - 先頭に、今の段（手元の設定があればその段、無ければ既定の段）を「今のまま」として置く
   - 続けて、その役の受ける段を安い順に置く（今の段と同じものは重ねない）
   - 最後に「既定に戻す」を置く
3. 選んだ結果を書く。今のままを選んだ役は何も打たない。段を選んだ役は、次のコマンドを打つ（両方の役が段なら 1 回にまとめてよい）。

```
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/ladder.py" setup --impl <段> --review <段>
```

   - 実装役だけなら `--impl <段>`、評価役だけなら `--review <段>` のみを付ける
   - 「既定に戻す」を選んだ役は `setup --reset 実装` か `setup --reset 評価` を打つ（その役の行だけを消す）。両方とも戻すなら `setup --reset` を打つ（models.md を消す）
   - 受けない段を渡すと 0 以外で終わり、受ける段を出して models.md を変えない。そのときは出力のとおりに選び直させる
4. 打ったコマンドの出力（書いたファイルのパスと中身、または既定に戻ったこと）を、そのまま人に示す。最後に `show` を打ち直して結果を確かめてもよい。
